# Project Demo

## Purpose

The visual demo should let a reviewer understand the product without installing Expo, configuring Supabase, or running the FastAPI service.

## Recommended walkthrough

Record a 30-60 second portrait capture with this sequence:

1. Login or signup.
2. Open the coach area and show the client list.
3. Generate or display an invite code.
4. Switch to the client account and claim the invite.
5. Show a prescribed workout and complete a check-in.
6. Return to the coach view and show adherence.
7. Open AI Coach and show one protected analysis request.

Keep account emails, tokens, API keys, and personal measurements out of the recording. Use seeded demo accounts or anonymized data.

## What the demo should not imply

The demo should not imply that production billing, App Store/Google Play publication, or external integrations are complete. Those states depend on external accounts, secrets, store review, and end-to-end validation.
